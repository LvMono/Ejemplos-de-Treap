# Ejemplos-de-Treap
Este proyecto implementa un **Treap (Tree + Heap)**, una estructura de datos que combina las propiedades de un árbol binario de búsqueda (BST) y un heap, utilizando claves y prioridades para organizar sus nodos. Está desarrollado en Python mediante la arquitectura MVC, separando el proyecto en tres carpetas: `model`, encargada de la lógica y los algoritmos del Treap; `view`, responsable de la interacción por consola; y `controller`, que conecta ambas capas. El archivo `main.py` permite ejecutar la aplicación.
